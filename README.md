## Installation⬇️

Before you download this repository, you should:

* Install the 2026 WPILib VS Code [here](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html)
* Create a new Java Command Robot (learn how to [here](https://docs.wpilib.org/en/stable/docs/software/vscode-overview/creating-robot-program.html))

Now we'll use this code for its intended purpose; I'll summarize the process in a nutshell:

1. Extract the downloaded file and select a controller type
2. Create a project in Wpilib
3. Find your project in File Explorer, then look for the **robot** folder (path directory is **src** -> **main** -> **java** -> **frc** -> **robot**)
4. Open the folder and copy the contents of the selected code into the robot folder

If you open your project on the 2026 WPILib VS Code software and check in the robot file, the new files should be in the right place; you can now build and deploy your project successfully. 😊
