## Installation⬇️

Before you download this repository, you should:

* Install the 2026 WPILib VS Code [here](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html)
* Create a new Java Command Robot (learn how to [here](https://docs.wpilib.org/en/stable/docs/software/vscode-overview/creating-robot-program.html))

Now we'll use this code for its intended purpose; I'll summarize the process in a nutshell:

1. Find your project in File Explorer, then look for the **robot** folder (path directory is **src** -> **main** -> **java** -> **frc** -> **robot**)
2. Open the folder and delete its contents
3. Download the repository as a ZIP file
4. Extract the ZIP file.
5. Navigate to the contents of the ZIP file and paste it into the **robot** folder except for the **README.md** and the GitHub excess

If you open your project on the 2026 WPILib VS Code software, it should be in the right place; you can now build and deploy your project successfully. 😊
